========================================================================
🚗 Dudu's Vehicle Routing Problem (VRP) Interactive Educational Lab
========================================================================

HOW TO RUN:
1. Double-click on "vrp.html" to open the app in any web browser (Chrome, Safari, Edge, Firefox).
2. That's it! It works 100% offline without installing any software or running a server.

FILES INCLUDED IN THIS FOLDER:
- vrp.html                   : Main interactive application
- mapss.png                  : Map background image
- dudu-car-dudu-running.gif  : Animated Dudu car sprite
- mapp.png                   : Alternative map background
- README.txt                 : Instructions file

FEATURES:
- Compare Messy Routes (Criss-cross) vs. Smart Routes (2-Opt VRP) vs. Multi-Car Teams.
- Drag delivery stops or click on the map to add custom customer locations.
- Dudu drives along the routes with package drop animations.
- Whole-number small distances (1-20 km range) for easy learning.
